| **Component**               | **Role**                       | **Description**                                                                                                                                                                                                                                                  |
| --------------------------- | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ANA Web                     | Primary ANA frontend SPA       | Talks to ANA API over HTTPS and streams chat tokens over SignalR. SSO auth against Entra (former Azure AD). Vite + React 18 + TS + Tailwind + MUI single-page app, hosted as Azure App Service.                                                                  |
| ANA API                     | Primary backend                | Orchestrates chat completion, exposes REST endpoints, hosts the SignalR hub, runs background jobs (e.g., storing Grain links via Zapier), and performs vector search against Azure Cognitive Search. .NET 8 / ASP.NET Core Web API, hosted as Azure App Service. |
| ANA Voice FE                | Voice frontend (SPA)           | Vite + React + TS app. MSAL auth, connects to the Voice Gateway over WebSockets (Socket.IO) for real-time audio streaming, hosted as Azure Static App.                                                                                                           |
| ANA Voice Gateway           | Voice backend                  | Single WebSocket gateway proxies audio between the client and the Azure OpenAI realtime model, and queries Azure Cognitive Search for internal document search. Thin NestJS app, hosted as Azure App Service.                                                    |
| Entra Identity              | Identity provider              | Azure AD (renamed Entra ID). Issues tokens to ANA Web, ANA Voice FE, and the backends via MSAL. Single tenant for all apps.                                                                                                                                      |
| Application Insights        | Observability                  | Azure Monitor logs/metrics/traces sink for all backend components (ANA API, sync FunctionApps, Voice Gateway).                                                                                                                                                   |
| SignalR                     | Real-time messaging service    | Azure SignalR service used by ANA API to stream chat completion tokens and status events to ANA Web.                                                                                                                                                             |
| SQL Server                  | Relational store               | Azure SQL database backing ANA API. Holds chat history, user/session metadata, configuration, sync bookkeeping, and Grain link records.                                                                                                                          |
| Zapier                      | Integration hub                | Receives Grain links from ANA API's background job and routes them onward (e.g., to Grain.AI workflows).                                                                                                                                                         |
| Grain.AI                    | External meeting/notes service | Source of meeting recordings/notes referenced via links pushed through Zapier.                                                                                                                                                                                   |
| Confluence                  | External knowledge source      | Atlassian Confluence wiki. Two access paths: (a) ANA API performs an on-demand full sync extracting Grain links; (b) ConfluenceSync FunctionApp runs incremental syncs into Blob Storage.                                                                        |
| Azure OpenAI deployment     | LLM for chat                   | Azure OpenAI resource hosting the chat/completion model. ANA API calls its Chat Completion API for non-voice conversations and tool use.                                                                                                                         |
| Azure OpenAI realtime model | LLM for voice                  | Azure OpenAI deployment of the realtime (speech-in/speech-out) model. The Voice Gateway streams audio to/from it.                                                                                                                                                |
| Azure Cognitive Search      | Vector + keyword search index  | HNSW vector indexes over synced content. Used by both ANA API and the Voice Gateway as the "Internal Document Search" tool. Indexes are populated from Blob Storage.                                                                                             |
| Blob Storage                | Synced-content store           | Azure Blob container holding the canonical synced documents (Confluence pages, email HTML attachments, Slack content). Source for Cognitive Search indexing.                                                                                                     |
| Azure Table Storage         | Sync state store               | Lightweight key/value store tracking incremental sync cursors/watermarks for the FunctionApps (e.g., last-modified tokens).                                                                                                                                      |
| ConfluenceSync FunctionApp  | Sync worker                    | Azure Function performing incremental Confluence sync. Writes content to Blob Storage, persists sync state to Table Storage, and extracts Grain links into SQL.                                                                                                  |
| MailSync FunctionApp        | Sync worker                    | Azure Function pulling email from MS Exchange via MS Graph and persisting HTML attachments/bodies into Blob Storage for indexing.                                                                                                                                |
| SlackSync FunctionApp       | Sync worker                    | Azure Function pulling Slack messages/files into Blob Storage for indexing.                                                                                                                                                                                      |
| Email MS Exchange           | External data source           | Microsoft Exchange mailboxes accessed via MS Graph API by MailSync.                                                                                                                                                                                              |
| Slack                       | External data source           | Slack workspace accessed by SlackSync to ingest channel/message content.                                                                                                                                                                                         |
